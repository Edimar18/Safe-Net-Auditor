📡 Safe-Net Auditor — Offline 802.11 Network Security Visualization

Ever wondered what's happening in the wireless spectrum around you?
Safe-Net Auditor turns an ESP32 into a passive 802.11 management frame
sniffer and visualizes threats on your Android phone in real time.

🔍 What it detects:
• Deauth attacks — who's getting kicked off the network
• Evil twin APs — duplicate SSIDs with matching BSSIDs
• Channel congestion — which 2.4GHz channels are saturated
• Suspicious vendors — Espressif chipsets commonly used in rogue APs

📊 What it shows:
• Live MGMT frame rate (global or per-AP)
• Trust Score (0–100) that drops under attack
• Flashing red BSSID fingerprints when deauth targets are detected
• 90-day incident heatmap and 24-hour traffic trends
• CSV & PDF exports for reporting

⚙️ How it works:
ESP32 (promiscuous mode) → USB-C Serial → Flutter app → SQLite
No cloud. No internet. No API keys. Fully offline.

🛠️ Stack: ESP32 / Arduino C++ | Flutter / Dart | SQLite | Custom Paint

Title: I built an offline WiFi threat visualizer with ESP32 + Flutter

Safe-Net Auditor is a fully offline 802.11 network security tool.

An ESP32 passively sniffs management frames on all 13 2.4GHz channels,
counting deauths, tracking per-AP frame rates, and detecting evil twin
SSIDs. Data flows over USB-C Serial to an Android app that shows:

- Live dashboard with trust score, MGMT frame counter, and RSSI
- Auditor tab with deauth spike graph and flashing BSSID fingerprints
  for APs under attack
- Evil twin scanner grouping duplicate-SSID BSSIDs with RSSI delta
- Spectrum analyzer with channel congestion bars
- 90-day incident heatmap and CSV/PDF exports

No cloud dependency. No internet. No API keys. Just ESP32 + phone.
